# 从 PDF 新建题库

在 **我的 → 数据管理 → 从 PDF 新建题库** 选择文件。识别完成后填写题库名称，对照原文件核对总题数、题目、选项和答案，点击 **新建题库**，再切换到新题库开始练习。

文字版 PDF 优先直接提取文字；文字不足的页面自动转为图片识别。扫描版使用随安装包提供的中文 ML Kit 模型，在本机逐页识别，无需购买接口、填写 API 密钥或下载识别模型。若文字乱码，可勾选“整份 PDF 按图片识别”后重新选择文件。识别过程请保持页面打开；返回会停止未完成的任务。

## 支持的题目结构

- 数字题号，例如 `1. 题目`、`1、题目`、`（1）题目`、`第1题`。
- 题型章节，例如“一、单项选择题”“二、多项选择题”“三、判断题”“四、填空题”“五、简答题”。
- 选择题选项为 A–H，支持逐行或同一行以空格分隔的 `A. 选项 B. 选项`。
- 题后 `答案：A`、`【答案】AC`、题干括号中的选项答案，或文末“参考答案”章节中的 `1.A 2.B`、`1-5 ABCDA`。
- 文末答案区可以按题型分节。无题型答案表遇到不同章节重复题号时，不会猜测对应关系；同题型重复编号也需要手动关联。
- 判断答案“对/错”“正确/错误”“√/×”。填空题用 `____` 或空括号表示空位，多空答案用分号分开；修改时每空答案占一行。

## 核对与限制

这是一套本机规则解析和 OCR 流程，不能保证任意 PDF 都能完整识别。清晰、单栏、编号一致、附带标准答案的题库最适合导入。分栏、表格、复杂公式、图片题、手写内容和嵌套数字列表可能需要手工补充或调整；题目配图不导入。请对照 PDF 核对总题数，不能只凭“待修正为零”判断完整性。

缺失答案、答案冲突、选项标签不完整和填空数量不一致会提示“待完善”，不会阻止新建。默认保留所有选中题目，之后可在题库页搜索、筛选“待完善”并编辑。未完善题目先以自评方式学习，不会自动判错；有可靠答案的题目正常判分。软件不会编造标准答案。

单次文件最多 50 MB、1000 页、200 万字符、5000 道题。相同文件允许新建独立副本，自动区分名称，原题库及学习记录保留。加密或限制内容提取的 PDF 需要使用有权访问且允许提取的副本。

新题库题目和目录写入应用私有文件，随后在独立数据库中保存学习记录。升级时沿用原应用包名、签名和数据库文件名；既有三套内置题库及其题目 ID、数据库结构保持不变。不要卸载应用或清除数据。现有“备份学习记录”功能只导出学习记录，未包含 PDF 和自建题库内容，请保留原 PDF。

## 验证

自动测试覆盖常见编号、全角标点、行内选项、文末答案、重复题号、缺失和冲突答案、跨页、不同题型、实际文字 PDF 提取，以及自建题库保存、重新加载和旧学习记录隔离。OCR 使用设备原生模型，仍需在实际手机上核对识别效果。
